Terms of Service: One Odd Fact

Last updated: 17 October 2026

One Odd Fact ("the tool") is a private command-line tool owned and operated by Aditya Narayan Pandey to upload videos to his own YouTube channel, @OneOddFact. It is not offered, sold or distributed to anyone else.

1. Who may use the tool

Only the owner of the @OneOddFact channel. The tool has no public interface, accounts or sign-up.

2. YouTube API Services

The tool uses YouTube API Services. Use of the tool is subject to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy. The tool complies with the YouTube API Services Terms of Service and Developer Policies.

3. What the tool does

It uploads videos created by the channel owner to the channel owner's own channel, using only the youtube.upload scope and the videos.insert method. It does not read, collect, analyse or modify any other YouTube data, and it never automates views, likes, subscriptions or comments.

4. Content

Only original content owned by the channel owner is uploaded. All content must comply with YouTube's Community Guidelines.

5. Privacy

Data handling is described in the Privacy Policy.

6. Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
