Privacy Policy

Last updated: 17 October 2026

One Odd Fact ("the tool") is a private, single-user tool run by Aditya Narayan Pandey, the owner of the YouTube channel @OneOddFact. It uploads videos to that channel.

YouTube API Services

The tool uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data the tool accesses

The tool asks for one Google permission: upload videos to YouTube (youtube.upload). It does not read your videos, comments, subscribers, analytics, contacts or any other account data.

What data the tool stores

Only the OAuth access and refresh tokens Google returns after sign-in. They are stored in a local file on the owner's computer, readable only by the owner's user account. No data is stored on any server.

How the data is used

The tokens are used only to authorise video uploads to the @OneOddFact channel. The tool sends video files and their titles, descriptions, tags and privacy settings to the YouTube Data API, and nothing else, to nowhere else.

Sharing

No data is shared with, sold to, or disclosed to any third party. There is no analytics, tracking or advertising.

Retention and deletion

The tokens are kept until access is revoked or the local file is deleted. You can revoke the tool's access at any time on your Google Account permissions page, which makes the stored tokens useless.

Changes

Changes to this policy will be posted on this page with a new "Last updated" date.
